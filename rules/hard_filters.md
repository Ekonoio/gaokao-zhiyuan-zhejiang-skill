# 硬过滤规则

本 Skill 只使用客观、可追溯的结构化条件。

## 段次与学历

- `application_stage` 与 `degree_level` 完全独立。
- 二段候选池允许本科、职业本科和专科同时存在。
- 不得以“二段”推断“专科”，也不得以“本科”推断“一段”。
- 计划段次不是二段时排除。
- 学历层次为空或无法识别时排除并记录原因。

## 固定考生选科

考生选考思想政治、历史、地理：

- `不限` 或 `不提科目要求` 可通过。
- 要求思想政治、历史或地理的组合按实际逻辑校验。
- 任何明确要求物理、化学或生物的专业直接排除。
- 不得用物理/物化要求的本科制造虚假机会。

## 直接排除

- 单科成绩未达到明确要求。
- 外语语种不符合明确要求。
- 明确限定性别且考生不符合。
- 明确体检限制与考生已知体检排除项冲突。
- 用户明确拒绝的专业、民办或中外合作类型。
- 专科不被接受时排除专科；只接受专科时排除本科和职业本科。

## 强制人工复核

- 听力状态、听力残疾或听力检查结果不明确。
- 招生章程尚未核验。
- 体检限制使用模糊表述，无法结构化确认。
- 单科、外语、性别或校区条件只存在于备注/章程，尚未形成可靠字段。
- 学费、校区、培养模式或中外合作信息缺失。

强制人工复核项可以保留在候选池，但不得宣称“无风险”。

## 本科与专科

- 该考生二段本科和职业本科默认只进入“冲”。
- 本科不得自动标为“稳”或“保”。
- 专科承担实际稳保功能，但不得推荐考生明确不愿就读的选项。
